Что делает программа: текстовый симулятор магазина. У героя 100 золотых, он может смотреть цены, покупать и продавать предметы (продажа — за половину цены) и смотреть содержимое рюкзака.
Как запустить: python main.py
Автопроверки (assert): python main.py --test

Проверка 1 (обычный сценарий): вход: 2 → «меч» → 4 → ожидание: золото 50, в рюкзаке «меч x1» → результат: «Куплено: меч за 50 зол.», «меч x1» ✔
Проверка 2 (граничный сценарий): вход: 2 → «дракон», затем покупка «меч» при золоте меньше 50, затем неверная команда «9» → ожидание: сообщения «Такого товара нет», «Не хватает золота», «Неизвестная команда», золото не меняется → результат совпадает ✔
